# 🤖 AI Chatbot Automation using n8n

## 📌 Overview

This project is an AI-powered chatbot built using n8n.
It processes user messages and generates intelligent responses using AI models like Gemini and Groq.

## ⚙️ Tech Stack

* n8n (Workflow Automation)
* AI Agent
* Google Gemini Chat Model
* Groq API (via HTTP Request)
* Simple Memory (for context retention)

## 🔄 Workflow

1. User sends a message
2. Trigger node activates
3. AI Agent processes input
4. Memory stores previous conversation
5. HTTP Request sends data to API
6. Response is returned to user
